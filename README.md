# FX Agent — тестовый авто-агент EUR/USD

Тестовый стенд «авто-ставок» на рост/падение валюты (мотив — вирусные видео с MT5).
Один Node-сервис: движок стратегии + риск-лимиты + Telegram-управление + мини-PWA админка.

**Честно и сразу:** это исследовательский инструмент. Никаких обещаний доходности.
При спреде ~1 pip скальпинг с целью 3 pips требует 66.7% угадываний только для нуля —
поэтому дефолтные цели широкие, издержки каждой сделки записываются и показываются,
а допуск к живым деньгам ступенчатый: **бэктест → sim → OANDA practice (демо) → live $10–50**.
Разгонов и мартингейла (как в видео) здесь нет: жёсткие потолки риска зашиты в код
(`src/agent/params.ts`, HARD_LIMITS) и kill-switch по дневному убытку.

## Архитектура

```
src/
  index.ts              точка входа: конфиг → store → движок → TG → PWA → планировщики
  agent/engine.ts       цикл: котировки → стратегия → риск → ордер → БД → уведомления
  agent/strategy.ts     momentum: движение > X pips за N сек → вход, TP/SL у брокера
  agent/risk.ts         лимиты + kill-switch + выходные FX
  broker/sim.ts         симулятор (случайное блуждание, спред, слиппедж) — без счетов
  broker/oanda.ts       OANDA v20: practice/live = одни и те же вызовы, разные хосты
  broker/metaapi-stub.ts альтернатива: Exness/MT5 через MetaApi (документированный стаб)
  backtest/             история Dukascopy (M1) + прогон ТОЙ ЖЕ стратегии + walk-forward
  news/calendar.ts      ForexFactory: не входим ±N мин вокруг важных новостей USD/EUR
  learn/                «память+обучение»: статы по часам → авто-блэкаут; ребэктест →
                        предложение параметров (применяется только после аппрува); LLM-дневник
  telegram/bot.ts       /agent_start|stop|status|report|params|mode|kill
  web/                  PWA: логин по паролю, графики, сделки, параметры, Web Push
public/                 PWA-статика (uPlot вендорен, без CDN)
prisma/schema.prisma    таблицы agent_* (общая Postgres, чужие таблицы не трогаем)
```

## Быстрый старт (локально)


### База данных: схема `fxagent` в Supabase (решение 31.07.2026)

Таблицы агента живут в **отдельной Postgres-схеме `fxagent`** внутри Supabase-проекта
Kiddeo ($0 вместо $10/мес за отдельный проект; полная изоляция имён от прода —
схема `public` не затрагивается, наружу через API она не выставлена, RLS не нужен).
Схема и таблицы уже созданы миграцией `fx_agent_init`.

`DATABASE_URL` для агента: в Supabase (проект Kiddeo → Connect) взять строку
**Session pooler** (прямое подключение IPv6-only — Render его не умеет) и добавить
`?schema=fxagent`:

```
postgresql://postgres.<ref>:<PASSWORD>@aws-0-eu-north-1.pooler.supabase.com:5432/postgres?schema=fxagent
```

Без `DATABASE_URL` сервис тоже стартует (MemoryStore, всё в памяти) — удобно для смоука.

### Бэктест (перед любыми деньгами)

```bash
npm run backtest -- --from 2024-01-01 --to 2026-07-01             # дефолт: momentum/market, EUR/USD
npm run backtest -- --from 2024-01-01 --to 2026-07-01 --optimize  # walk-forward подбор
npm run backtest -- --pair gbpusd --params '{"strategyType":"meanrev","entryMode":"limit"}' --optimize
npm run sweep    -- --from 2024-01-01 --to 2026-07-30             # 4 пары × 2 стратегии × 2 входа
```

История качается бесплатно с Dukascopy (кэш в `data/`). Отчёт: сделки, win-rate,
ожидание $/сделку **после издержек**, просадка. Отрицательное ожидание = live не включаем.
Оговорка: новостной фильтр в бэктесте не применяется (нет бесплатного исторического календаря).

### Стратегии и режимы входа

| Параметр | Значения | Смысл |
|---|---|---|
| `strategyType` | `momentum` \| `meanrev` | следование за движением / возврат к среднему |
| `entryMode` | `market` \| `limit` | платить спред и войти сразу / пассивная лимитка без спреда (риск неисполнения, TTL `entryTtlSec`) |
| `tradeHoursUtc` | напр. `7,8,9` | торговать только в эти часы UTC (пусто = все) |

Менять: в PWA или `/agent_params set strategyType meanrev`, `/agent_params set entryMode limit`,
`/agent_params set tradeHoursUtc 7,8,9` (сброс: `/agent_params set tradeHoursUtc -`).

### Режимы

| Режим | Что это | Как включить |
|---|---|---|
| `sim` | симулятор, без внешних счетов | `AGENT_MODE=sim` (дефолт) или `/agent_mode sim` |
| `live` + `OANDA_ENV=practice` | **демо-счёт OANDA** (бесплатно, тот же API) | ключи в env + `/agent_mode live` |
| `live` + `OANDA_ENV=live` | реальные деньги ($10–50 для теста) | сменить `OANDA_ENV` и ключи |

OANDA: счёт от $0, сделки от 1 юнита, EUR/USD спред ~0.9 pip, комиссии нет.
API-токен: My Account → Manage API Access. На счёте $10 ставьте `units` 100–500.

## Мини-PWA

Открыть URL сервиса → пароль (`ADMIN_PASSWORD`) → «Добавить на экран „Домой“».
Внутри: статус, кривая equity, сделки с издержками, параметры, предложения обучения,
кнопка 🔔 — Web Push. **Раз в час** приходит сводка «доход/расход за последние
`REPORT_WINDOW_MIN` минут» (push + Telegram). На iOS push работает только у
установленной на экран PWA (iOS 16.4+).

## Обучение + память

- **Память:** каждая сделка сохраняется с контекстом (спред, волатильность, час UTC,
  дистанция до новостей, снимок параметров) — таблица `agent_Trade`.
- **Ночью (00:10 UTC):** статистика по часам за 30 дней; устойчиво убыточные часы
  попадают в `autoBlackoutHours` (видно в PWA/логах, обратимо).
- **Еженедельно (вс 12:00 UTC, при `AUTO_RETRAIN=1`):** ребэктест на 90 днях →
  предложение параметров; применяется **только после аппрува** в PWA.
- **Ежедневно (06:00 UTC, при наличии `OPENAI_API_KEY`):** LLM-разбор журнала сделок
  в Telegram. Решения принимает человек.

## Деплой на Render

Этот сервис — долгоживущий процесс, **Vercel ему не подходит** (там serverless).
Поэтому старый Vercel-проект chatbot-tg перепрофилирован в **панель**: корневой
`vercel.json` переопределяет его сборку (без Next), а `api/[...path].ts` проксирует
всё на агента (URL агента задан в этом файле, переопределяется `AGENT_URL`). Пуши собираются зелёными;
чтобы прод-домен показывал панель с этой ветки — Settings → Git →
Production Branch = текущая ветка (или мердж в main).

`render.yaml` в корне (Blueprint). Free-тир засыпает через 15 мин без запросов, поэтому
в Supabase настроен keep-alive: pg_cron-джоб `ping-fx-agent` дёргает `/health` каждые
10 минут (отключить: `select cron.unschedule('ping-fx-agent');`). На платном `starter`
пингер не нужен.
После деплоя: env-переменные в дашборде, `npx prisma db push` запустить один раз локально
(в билд не встроено намеренно — БД общая). Graceful: на SIGTERM агент приостанавливается
и сам возобновляется после рестарта (`isRunning` в настройках).

## Крипто-эксперимент выходных (CRYPTO_WEEKEND=1)

FX закрыт с пт 20:45 до вс 21:15 UTC; крипто-CFD Exness (BTCUSDm/ETHUSDm) торгуются 24/7.
При `CRYPTO_WEEKEND=1` (только live+metaapi) движок поднимает вторую «ногу»: котировки
крипто-символа стримятся круглосуточно (echo непрерывно учит расписание, при старте
прогревается историей Dukascopy), а **входы разрешены только пока FX закрыт**.
Пресет: `CRYPTO_PRESET=btc` (echo/limit) или `eth` (momentum/limit); параметры зашиты
в `CRYPTO_PRESETS` (src/agent/params.ts) и на лету не меняются. Масштаб цены: пип BTC = $10,
ETH = $1; 1000 юнитов BTC = 0.01 лота (минимальный у Exness). У ноги свой дневной лимит
убытка — при срабатывании закрывает свои позиции и молчит до следующего дня UTC,
глобальный kill-switch и основной EUR/USD-контур не трогаются.

**Честная рамка:** walk-forward крипту НЕ подтверждает (docs/CRYPTO-SWEEP-2026-07-31.md:
у BTC-лидеров train отрицательный; «выходная прибыль» echo — артефакт test-периода).
Это сбор форвард-данных на демо, не торговая рекомендация.

## Ансамбль виртуальных стратегий (ENSEMBLE, включён по умолчанию)

В live-режиме движок передаёт каждый живой тик EUR/USD в ансамбль: 5 стратегий
(meanrev = копия живого контура, spreadweather, momentum, echo, impulse) торгуют
**виртуально** — та же пессимистичная модель лимитных филлов, что в бэктесте,
сделки в БД под mode=`virtual`, symbol=`EUR_USD~<key>`. Деньги не задействованы.
Прогрев echo/spreadweather — историей Dukascopy с реальным спредом при старте.

Зачем: (1) spreadweather впервые проверяется на настоящем живом спреде;
(2) разница виртуального и реального meanrev = чистый замер качества исполнения;
(3) «лицензии» (14 дней, ≥10 сделок, net>0) пока **справочные** — смотрим, кому
ансамбль дал бы объём, прежде чем доверить это коду. Смотреть: карточка
«Ансамбль» в PWA или `/agent_ensemble` в Telegram. Выключить: `ENSEMBLE=0`.

При включённой крипто-ноге (CRYPTO_WEEKEND=1) поднимается и **крипто-ансамбль**:
те же 5 ролей (`btc-*`, пороги ×4) на BTC-стриме ноги — 24/7, включая выходные;
btc-echo дублирует live-пресет ноги (замер исполнения на крипте), btc-spreadw
впервые собирает данные вообще (в бэктесте не хватило ask-истории).

Третий этаж — **мультирыночная нога** (MARKETS, включена по умолчанию вместе с
ансамблем): пять победителей свипа пяти рынков (docs/PORTFOLIO-SWEEP-2026-08-01.md)
торгуют виртуально на живых котировках своих рынков — золото `gold-impulse`,
нефть `oil-impulse`, GBPJPY `gj-meanrev`+`gj-vprofile`, S&P500 `sp-matrend`.
Одно дополнительное streaming-соединение MetaApi на все четыре символа
(XAUUSDm, USOILm, GBPJPYm, US500m), цены масштабируются в пипс-пространство
бэктеста (см. `MARKET_LEGS` в `src/agent/params.ts`), сделки в БД под
mode=`virtual`, symbol=`XAU_USD~gold-impulse` и т.п. Эти рынки живут сессиями:
ночью и в выходные котировок нет — книги ждут. Выключить: `MARKETS=0`.

## Мейкер-эксперимент на Binance Futures testnet — ЗАКРЫТ 03.08.2026

**Жанр похоронен по команде владельца** (вердикт вынесен 02.08 по заранее
зафиксированному правилу): 323 круга, −45.39$, ни одного плюсового дня — и это
на тестнете, который льстит мейкеру. Подробности: docs/MAKER-CLOSURE-2026-08-03.md.
`MAKER_TESTNET` больше не читается; при старте остаточные ордера/инвентарь на
тестнете подчищаются автоматически, пока в env есть ключи. Ниже — описание
эксперимента, каким он был:

CFD-версия страддла в бэктесте мертва: собранный шум съедает adverse selection
(docs/IDEAS-2026-07-31.md). На бирже структура издержек другая — пассивная сторона
платит известную комиссию мейкера (~0.02%), а post-only (GTX) гарантирует, что
тейкером мы не окажемся. Нога котирует обе стороны BTCUSDT-перпетуала в тихом
рынке (StraddleStrategy-гейт), обе исполнились → круг закрыт (нетто-ноль);
одна → инвентарь с пассивной выходной котировкой, стоп/тайм-стоп по рынку.
Учёт по userTrades (realizedPnl + commission каждого филла), сделки в БД под
mode=`testnet`. Деньги фейковые; стакан настоящий, но тестнет-филлы льстят
(очереди HFT там нет) — плюс здесь лишь открывает следующие ворота, не отменяет их.
Ключи: testnet.binancefuture.com → API Key. Bybit-тестнет не подошёл: геоблокирует
US-регион, где живёт Render.
