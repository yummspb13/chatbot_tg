# Дни рождения детей с «Модного подиума» — база для рассылок

Источник: таблица `PodiumRegistration` в БД Kiddeo (Supabase, проект `flweimcadtsksqzyllno`).
Регистрации собирались **18–25 июля 2026**, всего **63 строки**.

Дата расчёта отчёта: **04.08.2026**. Файлы актуальны на эту дату; для пересчёта запустите
`birthday-mailing.sql`.

## Как восстановлен возраст

В форме год рождения не спрашивали — есть только:

- `childBirthDay` / `childBirthMonth` — день и месяц ДР;
- `childAge` — возраст, указанный родителем на момент регистрации;
- `createdAt` — дата регистрации.

Год рождения восстанавливается так:

```
если ДР уже наступил в год регистрации (на дату createdAt):
    birth_year = год(createdAt) − childAge
иначе:
    birth_year = год(createdAt) − childAge − 1
```

Ошибка ±1 год возможна только если родитель указал не текущий возраст ребёнка,
а тот, который ребёнку исполнится. Проверить это по данным нельзя.

## Дедупликация

Один ребёнок мог попасть в таблицу несколько раз: помимо `PARTICIPANT`/`WAITLIST`
на него заводили отдельную строку `SPECTATOR`. Ключ ребёнка — телефон + имя +
день/месяц ДР; из дублей берётся строка с заполненным возрастом, `SPECTATOR` — в
последнюю очередь.

63 строки → **58 уникальных детей** (5 строк `SPECTATOR` оказались дублями).
