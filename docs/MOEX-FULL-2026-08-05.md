## ГЛАВНАЯ ОГОВОРКА — спред-модель льстит второму эшелону

Скан платил константные 0.02% спреда. Для SBER/LKOH это честно; для бумаг
типа SPBE (77₽, ход 150 пипсов/час — 1.5% цены в час!) реальный стакан бывает
в разы шире. Проходы второго эшелона могут быть артефактом модели.

**Валидация запланирована**: src/backtest/moex-spread-check.ts снимает живые
стаканы 15 тикеров-победителей каждые 30с в течение ~20 мин торговой сессии
(T-Invest, read-only) → медиана/p90 спреда в % → вердикт по каждому: модель
честна (×≤1.5) / пересчитать (×≤3) / льстила (×>3). Запуск утром 05.08 в
сессию; расширение MOEX-ноги — только после этой проверки и только по
команде «подключай».
