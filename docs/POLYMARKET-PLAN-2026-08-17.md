# План: Polymarket-бот «один в один» с ролика — 2026-08-17

Запрос владельца: воспроизвести систему из ролика (hot-garbage // POLYMARKET
BOT) по полям, блокам и функциям + понять экономику. Рамка проекта прежняя:
никаких обещаний доходности; деньги — только за доказанным краем; каждый этап
имеет гейт и похоронный критерий. Урок дня: BTC = $64k по НАШЕЙ базе (я
ошибочно утверждал >$100k из памяти — фид ролика оказался актуальным).

## Что делает система ролика (роли → наши компоненты)

| Блок ролика | Функция | Наш компонент |
|---|---|---|
| Фид (BTC/ETH, стакан, лента, вола, инвентарь) | входные фичи | MetaApi-стрим (есть) + Polymarket CLOB (новый коллектор) |
| Neural Shell, 48 units, «fair price %» | вероятность UP на 5-мин горизонте | фичефрейм майнера-2 + логит/мини-MLP, walk-forward + Бонферрони (конвейер готов) |
| MFT Maker | лимитки на обе стороны вокруг fair | новый мейкер-движок по образу EnsembleLeg |
| Cheap Complete Sets | YES+NO суммарно <$1 → безрисковые ¢ | сборщик сетов (сигнал: sum(ask_yes+ask_no) < 1−ε) |
| Hedge Flow (Sankey) | ребаланс инвентаря | противоположная сторона / соседняя экспирация |
| Resolution Grid / Lifecycle | учёт экспираций | пайплайн резолюций (каждые 5 мин) |
| Дашборд целиком | витрина | наша PWA: uPlot + SVG (Sankey, scatter, сеть) |

## Этапы, сроки, гейты

**Этап 1 — Разведка данных (read-only, $0, ~день кода + 5-7 дней сбора).**
Коллектор Polymarket CLOB API (публичный, без ключей): 5-минутные рынки
BTC/ETH up/down — стаканы обеих сторон раз в 5-10с, сделки, резолюции.
Метрики: частота окон sum<\$0.99, их глубина в \$, время жизни, спред стороны,
теоретический \$/день на слайсе \$100 ПОСЛЕ проскальзывания.
ГЕЙТ: окна существуют и вмещают хотя бы микро-размер. Нет → хороним торговую
часть (дашборд можно строить поверх нашего полигона всё равно).

**Этап 2 — Модель fair (параллельно, 2-3 дня).** Предсказуемость 5M-исходов
нашим конвейером: фичи из фичефрейма (час/стрик/вола/объём...) на истории
резолюций. Walk-forward 70/30, порог из кумулятивного леджера (51 251+).
ГЕЙТ: edge модели > спред стороны. Нет → остаёмся чистым сет-арбитражёром
без направленного мейкинга.

**Этап 3 — Бумажный мейкер (неделя кода + 2 недели прогона).** Виртуальные
лимитки на ЖИВОМ стакане по механике нашего ансамбля (mode=virtual, БД,
лицензии). Порог лицензии мейкера: 14 дней, ≥50 филлов, net>0 после модели
проскальзывания. Учтён урок мейкера-1 (Binance, −45.39\$): adverse selection
мерим явно — pnl филлов против движения следующих 30с.

**Этап 4 — Дашборд 1:1 (2-3 дня, параллельно).** Все панели ролика поверх
НАШИХ данных: Wallet/PnL/fills/wr/set-edge, Lifecycle, Resolution Grid,
Neural Shell (наша модель), Edge Matrix, Hedge Flow, live-тикер событий.

**Этап 5 — Деньги (только после гейтов 1-3 и решения владельца).**
Отдельные вопросы вне моей зоны: доступ к Polymarket из РФ (ToS/гео),
рейлы USDC/Polygon, кошелёк. Старт микро \$50-100, лесенка размера — как
везде у нас. Любая цифра доходности до этапа 1 — выдумка; формула окупаемости:
(частота окон × глубина × наш слайс − проскальзывание − издержки рейлов) ×
время. Числа подставит разведка.

## Риски честно

1. Ликвидность 5-минуток тонкая — окна могут не вмещать даже \$100.
2. Adverse selection — главный убийца мейкеров (наш урок №1).
3. Оракул/резолюция — редкие спорные исходы.
4. Комплаенс/доступ РФ и операционка крипто-рейлов — зона владельца.
5. Цифры ролика (×366 от депозита) не верифицированы: кошелёк обрезан.
