## Дополнение (вечер 21.09): три оси владельца — «вероятности / живые кейсы / докрутка»

Запрос: «ещё раз пройтись по гипотезам: вероятности, живые кейсы у людей с
проверкой, докручивание наших». Три быстрых проверки по горячим следам:

1. **Трейл по семействам (изоляция на нефти).** Те же сигналы oil-impulse,
   δ ∈ {0, 0.1, 0.2, 0.3}, два окна, филлы cross: на контроле (01-28.08) все
   варианты в минусе (−19..−75$), на простое δ=0.2 худший (−86$) при δ=0.1
   +1$ и δ=0 −12$. Немонотонно → шум поверх убыточной ячейки, но δ=0.2
   стабильно худший. Правило: **трейл — только у meanrev** (SIBN/AFKS: 9/9 в
   плюс живьём); импульсным семействам (alrs-impulse, oil-hh) трейл не даём.
2. **Ночной гэп РФ-нефтянки против нефти.** P(знак гэпа = знак ночного хода
   WTI) = 45-52% на train (469 ночей), test шумит: **связи нет**. Найденный
   внутридневной лаг нефть→нефтянка (t=8) работает только пока оба рынка
   торгуются одновременно; ночью открытие определяют рубль/новости/потоки.
   Правило «держать через ночь по нефти» — отклонено, GAP-хвосты остаются.
3. **Перекос Polymarket как вероятность для BTC.** При |P(up)−0.5| ≥ 0.15
   BTC в следующие 30 мин идёт ПРОТИВ перекоса в 53.4% случаев (z=−4.1,
   средний ход −1.9бп, t=−3.9; 3591 наблюдение 18-29.08). Первичный запрос
   показывал 35% — артефакт: 24% снапов с застывшим refPx (умиравший стрим)
   считались «несогласием»; исключены. Остаток — внутрибакетный возврат BTC
   размером с издержки; как самостоятельный сигнал не годится, как
   отрицательная фича для матрицы вероятностей (§ниже) — кандидат. OOS
   невозможен, пока refPx мёртв (MetaApi).

Что осталось в плане (по приоритету):
- **P(win | условия входа)** — калиброванная вероятность выигрыша наших же
  сигналов по записанным фичам (спред, вола окна, час, новость, сторона,
  семейство), walk-forward август→сентябрь; гейт «пропуск входа ниже
  BE-порога ячейки». Флагман: умножает все найденные края.
- **Верифицированные живые кейсы**: автоследование Т-Банка (верификация
  брокером, РФ), Darwinex (открытый API верифицированных стратегий),
  on-chain топ-кошельки Polymarket, ЛЧИ Мосбиржи — извлекаем ПРОФИЛЬ
  (актив/горизонт/частота/wr/DD), не цифры; тестируем недостающие семейства.
- Докрутка: стоп SIBN (SL ∈ {1×,1.5×,2×}TP), ETH-клон btc-matrend, oilguard с
  Brent и σ по дневной воле, разморозка EUR live (решение владельца).

Леджер после дополнения: **259 985**.
