Решение владельца: делаем. Разведка (docs/MOEX-2026-08-03.md) дала карту:
meanrev-кластер на TATN/GAZP/ROSN/SBER + impulse на ROSN/MGNT, всё — после

проект: виртуал → песочница → микро, деньги двигаются последними.

## Шаг 1 — со стороны владельца (единственное, что нужно от вас)

1. **Брокерский счёт Т-Банка** (если ещё нет). Тариф — «Трейдер»
   (0.04%/сторона): наша модель разведки закладывала 0.05% — с запасом.
   Тариф «Инвестор» (0.3%) для нашего интрадея непроходим по арифметике.
2. **Токен T-Invest API**: приложение/сайт → Настройки → Токены T-Invest API →
   выпустить **токен «только для чтения»** (read-only, этого хватит для всей
   виртуальной фазы). Положить в Render → Environment как `TINKOFF_TOKEN`
   (как делали с ключами Binance — в чат не постить).
3. Торговый (full-access) токен НЕ выпускать до окончания виртуальной фазы.

## Шаг 2 — моя стройка после появления токена

1. **Смоук доступности**: invest-public-api.tinkoff.ru с Render-сервера
   (риск №1 — гео-фильтр не-RF IP; проверяется одним запросом. Если закрыт —
   обсудим RF-хостинг ноги отдельным микросервисом, решение не сегодня).
2. **MoexQuoteFeed**: стрим минутных свечей/цен по TATN, GAZP, ROSN, SBER
   (LKOH исключён — комиссия его съедает, MGNT под вопросом ликвидности стакана).
3. **Виртуальная MOEX-нога** — тот же механизм, что мультирыночная:
   сделки в БД mode=virtual, symbol='TATN~tatn-meanrev' и т.п., участники:
   tatn-meanrev (звезда разведки: test +41.4 net, wr 67%), gazp-meanrev,
   rosn-impulse. Деньги не затрагиваются вообще.
4. Часы сессии: 06:50–15:40 UTC + вечерняя 16:05–20:50; овернайт-позиций нет
   (форс-выход перед разрывом — как в разведке).

## Шаг 3 — ворота дальше (не раньше чем через 2-3 недели виртуала)

- Виртуал в плюсе после модельных комиссий → песочница T-Invest (фейковые
  деньги, реальный API-контур) → micro live с жёсткими лимитами (наш стандарт:
  дневной стоп, kill-switch, размер позиции ~30 тыс. ₽).
- Честные риски зафиксированы заранее: изолированность рынка (прецедент
  месячной остановки 02.2022), комиссионная чувствительность (выживают только
  широкие цели), ликвидность вечерней сессии тоньше основной.

Разведку обновляем ежемесячно одной командой (moex-sweep) — карта не должна
протухнуть, пока идёт бумажная часть.
