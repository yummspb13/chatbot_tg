**Данные:** Dukascopy, EUR/USD M1, 2024-01-04 → 2026-07-29, **932 684 минутки** (~2.5 года).
**Код:** тот же `src/agent/strategy.ts` + `src/agent/risk.ts`, что торгует вживую.

## Вывод

**Сама стратегия — монетка, весь убыток — издержки.** До спреда лучшая комбинация
на честном test-периоде даёт ≈0 (+8$ на 681 сделку), после спреда — устойчивый минус:
каждая сделка в среднем платит ~0.9–1 pip рынку. Это в точности «рулеточная» математика,
которую мы считали заранее: при цели/стопе 20/20 pips и издержке ~1 pip нужен win-rate ≥ 52.5%,
а momentum даёт 48%.

**Решение по протоколу проекта: live НЕ включаем.** Ожидание отрицательное → допуска
к реальным деньгам нет. Стенд полностью рабочий (sim / OANDA practice / PWA / отчёты) —
он и нужен для поиска правил с положительным ожиданием.

## Что пробовать дальше (гипотезы для этого же стенда)

1. **Mean-reversion вместо momentum** в тихие часы (азиатская сессия): порог-разворот,
   а не следование. По минуткам EUR/USD возврат к среднему исторически выражен сильнее.
2. **Сессионные фильтры:** торговать только Лондон/NY-открытия; статистика по часам
   уже копится в `agent_Trade` и видна в PWA.
3. **Реже и крупнее цели:** TP/SL 30–50 pips на H1-сигналах — доля издержек падает до ~2–3%.
4. **Новостной фильтр в бэктесте:** добавить исторический календарь (платный или скрейп),
   чтобы честно мерить его вклад.
5. Каждую гипотезу — сначала `npm run backtest -- --optimize`, walk-forward, и только при
   положительном test-ожидании — practice, потом micro-live.

Повторить: `npm run backtest -- --from 2024-01-01 --to 2026-07-30 --optimize`
(полный JSON: `data/backtest-report.json`, в git не коммитится).
