# MOEX-разведка: наши стратегии на российских фишках — 2026-08-03

Тезис владельца: изолированный рынок (~80% оборота — физики, иностранных
арбитражёров после 2022 нет) должен быть паттернистее. Проверка офлайн, ноль
риска: бесплатный ISS API Мосбиржи → 2.5 года минуток (2024-01 → 2026-07,
~650k на тикер) → ПРОДОВЫЕ стратегии из strategy.ts (meanrev/impulse/matrend
× market/limit) → издержки: спред-модель 0.02% + комиссия 0.1% нотионала за
круг (розничный тариф) + форс-выход на сессионных разрывах (овернайт-гэпы
через стопы не прыгают). Вердикт: плюс на train И test ПОСЛЕ комиссий.
Инструменты: src/backtest/moex-data.ts, moex-sweep.ts · JSON: data/moex-report.json.

## Итог: 13 из 180 ячеек — и снова кластеры

| Тикер | Прошло | Лучшее (net после комиссий) |
|---|---|---|
| TATN | 2 | **meanrev: test +41.4 при wr 67%** — звезда разведки (обе версии входа) |
| GAZP | 4 | meanrev согласованно (все 4 — meanrev, обе TF-ширины) |
| ROSN | 4 | meanrev + **impulse** (сырьевая подпись — как у него на WTI/золоте!) |
| MGNT | 2 | impulse/limit: test +28.4 на 131 сд |
| SBER | 1 | meanrev/limit на грани (+6) |
| LKOH | 0 | комиссия 6.8п/круг съела всё (дорогая акция) |

1. **Meanrev — кластер на 4 тикерах из 6.** Возврат к среднему на российских
   фишках работает семейно — ровно то, что ждёшь от рынка физиков без HFT-плотности.
2. **Impulse подтвердил свою «сырьевую» природу** третьим независимым классом
   активов: WTI → золото → ROSN/MGNT.
3. **Комиссия — хирургический барьер**: SBER gross +24 → net +0.6. Выживают
   только широкие цели (tp 60–140 пипсов масштаба), скальпинг мёртв по
   построению — мем-урок подтверждён и здесь.

## Честные оговорки

- Спред-модель константная (0.02%) — реальный стакан то уже, то шире;
  выборки 33–131 сделка — средние; walk-forward одинарный (70/30), сейфа
  для MOEX пока нет.
- Главный вопрос MOEX — не эдж, а ДОСТУП и инфраструктура: наш MT5-стек не
  при делах, нужен RF-брокер с API (Tinkoff Invest), плюс рыночный риск
  изоляции (прецедент: месяц закрытого рынка в 2022).

## Решение

Флаг поставлен, десант не высаживаем: три живых контура и 19+ виртуалов уже
на пределе внимания. MOEX-ветка замораживается как ДОКАЗАННАЯ КАРТА до момента,
когда владелец решит открывать RF-брокерский счёт — тогда первым шагом станет
Tinkoff-адаптер и виртуальный форвард на TATN-meanrev / ROSN-impulse.
Повторный прогон разведки — через месяц данных (одна команда).
